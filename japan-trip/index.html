Train playbook

Static times can change. The safest design is to use the official timetable links for the next train.

Narita → Honjo-azumabashi

Preferred: Keisei Access Express / through service to the Toei Asakusa Line. No limited-express supplement is required for Access Express. Hotel says Narita → Honjo-azumabashi is about 1 hour.

Fare reference: Keisei publishes ¥1,290 to Asakusa and ¥1,170 to Oshiage from Narita T2-3. Honjo-azumabashi is between them, so use the station fare machine/IC fare for the exact amount.

Missed-train rule

Do not memorize a single train. At the station, open the live official timetable or Google Maps, set the current time, and choose the next train that keeps the same route. For Narita, prefer direct/through services even if another connection is a few minutes faster.
